# Scripts — moduli della pipeline (Claude li esegue)
- trova-contatti/  → trova attivita + estrae e VERIFICA email reali
- genera-sito/     → unisce template + config + images → sito pronto

- prepara-mail/    → bozza email col video, pronta all'invio
- aggiorna-indice/ → rigenera INDICE.md dallo stato di PIPELINE.xlsx
